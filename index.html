Settings & data

TCX contains time, distance, speed, kcal and heart rate (if available) from the first to the last moment with movement. Values come from the device and may be inaccurate.

Experiment console (Control Point 0x2AD9)

Set Speed (02 …) is blocked if it is above the limit, larger than the maximum change, or comes too soon after the last speed command. Start (07) only after confirmation, Set Target Heart Rate (06) not at all. Everything else is sent raw.

    Privacy

    No accounts, no server, no tracking, no external scripts or fonts. Only if you switch on the optional route map, it loads map data from a map server (named on the route card). Settings (limit, ramp, language, theme, accepted notice) are stored only locally in this browser. The saved runs stay on this device too.
