Experimentier-Konsole (Control Point 0x2AD9)

Set Speed (02 …) wird blockiert, wenn er über dem Limit liegt, größer als die maximale Änderung ist oder zu kurz nach dem letzten Speed-Befehl kommt. Start (07) nur mit Bestätigung, Set Target Heart Rate (06) gar nicht. Alles andere geht roh raus.
